# Relatório Individual — João Pedro Buhler

## Projeto: Sellf

Durante o desenvolvimento do projeto Sellf, participei principalmente da implementação do backend, integração entre frontend e banco de dados e desenvolvimento das funcionalidades de autenticação do sistema.

Fui responsável pela criação das rotas da API utilizando Node.js e Express, além da configuração da conexão com o banco de dados MySQL. Também implementei funcionalidades importantes, como cadastro e login de usuários, autenticação com JWT, criptografia de senhas com bcrypt e validação de CPF.

Além disso, participei da integração entre o React e o backend utilizando Axios, garantindo o funcionamento correto das sessões e da comunicação entre cliente e servidor.

## Conhecimentos Adquiridos

Durante o projeto, aprendi mais sobre:

- Desenvolvimento backend com Node.js e Express
- Construção de APIs REST
- Integração entre frontend e backend
- Segurança com cookies httpOnly
- Criptografia de senhas com bcrypt
- Validação de CPF
- Manipulação de banco de dados MySQL
- Trabalho em equipe utilizando GitHub

## Dificuldades Encontradas

Uma das dificuldades foi configurar corretamente a autenticação utilizando JWT e cookies, garantindo segurança e funcionamento correto das sessões.

Também tive dificuldades relacionadas ao banco de dados, principalmente em problemas com caracteres acentuados nas tabelas.

Além disso, a integração entre frontend e backend exigiu vários testes até que as requisições funcionassem corretamente.

## Como as Dificuldades Foram Resolvidas

Os erros do banco de dados foram resolvidos ajustando os relacionamentos entre tabelas e alterando o encoding para `utf8mb4`.

Já os problemas de autenticação e integração foram solucionados com testes práticos, ajustes no Axios e melhorias na configuração de cookies e JWT.

## Considerações Finais

A primeira parte do projeto foi importante para relembrar e aprimorar meus conhecimentos em backend e integração de sistemas.

Foi possível colocar em prática conceitos de APIs REST, autenticação, banco de dados e comunicação entre frontend e backend, além de melhorar minha capacidade de resolver problemas e trabalhar em equipe.
