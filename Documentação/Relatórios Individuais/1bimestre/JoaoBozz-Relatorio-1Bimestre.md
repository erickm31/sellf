# Relatório Individual — João Vitor Mendes Bozz

## Projeto: Sellf

Durante o desenvolvimento do projeto Sellf, participei principalmente da organização visual do sistema, estruturação do frontend e padronização da identidade visual do projeto.

Fui responsável pela pesquisa e separação de paletas de cores para auxiliar a equipe na escolha da identidade visual do sistema. Após comparações e testes, definimos a utilização da paleta azul como padrão principal do projeto.

Também realizei a renovação e adaptação da logo do projeto, criando diferentes versões para melhor utilização em diversos contextos, como modo claro, modo escuro e arquivos em formato PNG.

Além disso, criei um Canva para facilitar a organização do frontend e auxiliar no planejamento visual das telas antes da implementação em código.

Na parte de desenvolvimento, criei a estrutura completa de pastas do projeto, organizei os arquivos base do frontend e desenvolvi o CSS global e o sistema de variáveis de cores para manter a padronização visual da aplicação.

Também participei diretamente da criação das páginas principais do sistema, como login, cadastro e landing page, além da implementação de componentes como header e footer.

Outra contribuição importante foi a criação de prompts organizados para facilitar o uso de inteligência artificial durante o desenvolvimento do projeto.

## Conhecimentos Adquiridos

Durante o projeto, aprendi mais sobre:

- Organização de projetos frontend
- Estruturação de aplicações React
- Padronização visual utilizando CSS global
- Criação de variáveis CSS
- Planejamento de interfaces
- Identidade visual e escolha de paletas de cores
- Desenvolvimento de landing pages
- Criação de componentes reutilizáveis
- Trabalho em equipe utilizando GitHub
- Utilização de inteligência artificial para auxiliar no desenvolvimento

## Dificuldades Encontradas

Uma das dificuldades foi organizar a identidade visual do projeto de forma que todas as páginas mantivessem um padrão consistente.

Também houve desafios na criação da estrutura inicial do frontend e na adaptação das telas planejadas no Canva para o código.

Além disso, encontrar uma paleta de cores que combinasse com a proposta do sistema exigiu vários testes e comparações.

## Como as Dificuldades Foram Resolvidas

Os problemas relacionados à organização visual foram resolvidos com a criação de variáveis globais de cores e padronização do CSS.

Já as dificuldades na implementação das telas foram solucionadas utilizando o Canva como base de planejamento e realizando ajustes progressivos no frontend.

A escolha da identidade visual foi definida após testes entre diferentes paletas e discussão em equipe para selecionar a opção mais adequada ao projeto.

## Considerações Finais

O desenvolvimento da primeira parte do projeto foi importante para aprimorar meus conhecimentos em frontend, organização visual e estruturação de aplicações web.

Foi possível aplicar conceitos de design, padronização visual e desenvolvimento de interfaces, além de melhorar minha capacidade de organização, planejamento e trabalho em equipe durante o desenvolvimento do sistema.
