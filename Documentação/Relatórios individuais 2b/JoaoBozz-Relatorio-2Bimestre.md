# Relatório Individual — João Vitor Mendes Bozz

## Projeto: Sellf

Durante o segundo bimestre do desenvolvimento do projeto Sellf, participei principalmente da evolução da interface do sistema, da padronização dos componentes e da implementação das principais telas do frontend.

Uma das minhas principais contribuições foi a reorganização do componente Header. Realizei sua separação em duas versões distintas: uma destinada à Landing Page e outra para as páginas internas do sistema, como a Home e demais áreas da aplicação. Essa divisão tornou o código mais organizado, reutilizável e adequado para cada contexto.

Também fui responsável pela criação, padronização e organização de diversos componentes de interface (UI), como botões, cards, campos de entrada (inputs) e outros elementos reutilizáveis. Essa padronização facilitou o desenvolvimento das telas e garantiu maior consistência visual em toda a aplicação.

Além disso, desenvolvi a página Home do sistema, implementando as principais seções responsáveis pela exibição dos produtos, incluindo áreas de destaque, lojas recomendadas, produtos próximos ao usuário e demais containers presentes na interface inicial.

Outra contribuição importante foi a melhoria das páginas de login e cadastro. Realizei ajustes tanto na estrutura em JSX quanto na estilização em CSS, deixando essas telas mais alinhadas com a identidade visual adotada pelo restante do sistema e proporcionando uma experiência mais consistente para o usuário.

## Conhecimentos Adquiridos

Durante esta etapa do projeto, aprendi mais sobre:

- Organização e reutilização de componentes React
- Padronização de interfaces utilizando componentes de UI
- Estruturação de páginas mais complexas
- Desenvolvimento da página Home de uma aplicação web
- Boas práticas de organização de JSX e CSS
- Reutilização de componentes para facilitar a manutenção do projeto
- Consistência visual entre diferentes telas
- Desenvolvimento colaborativo utilizando GitHub

## Dificuldades Encontradas

Uma das principais dificuldades foi organizar os componentes de forma que fossem reutilizáveis em diferentes partes do sistema sem comprometer a organização do código.

Também houve desafios na construção da página Home, devido à quantidade de seções e componentes necessários para sua composição.

Além disso, foi necessário adaptar as páginas de login e cadastro para que seguissem o mesmo padrão visual adotado no restante da aplicação.

## Como as Dificuldades Foram Resolvidas

Os desafios relacionados à organização dos componentes foram resolvidos por meio da separação da interface em componentes reutilizáveis e da padronização dos elementos de UI.

As dificuldades na construção da página Home foram superadas com a divisão da tela em diferentes seções, permitindo um desenvolvimento mais organizado e facilitando futuras manutenções.

Já as melhorias nas telas de login e cadastro foram realizadas com ajustes graduais no JSX e no CSS, garantindo maior integração com a identidade visual do sistema.

Foi possível aprofundar o uso de componentes reutilizáveis, melhorar a estrutura do código e contribuir para uma aplicação mais organizada, consistente e de fácil manutenção, além de fortalecer minhas habilidades de desenvolvimento em equipe.
