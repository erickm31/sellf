# Relatório Individual — Bruno Arruda Shiba

## Projeto: Sellf

Durante o segundo bimestre do desenvolvimento do projeto da loja virtual, trabalhei principalmente nas telas do site e na organização visual do sistema.

Uma das minhas contribuições foi ajustar o menu superior (Header) do site. Fiz duas versões dele: uma para a página inicial (Landing Page) e outra para as páginas de dentro do sistema, como a Home. Assim o código ficou mais simples de entender e de usar em cada parte do site.

Também ajudei a criar e organizar alguns elementos usados em várias telas, como botões, cartões de produto e campos para digitar informações. Isso deixou o site com uma aparência mais parecida em todas as páginas.

Além disso, participei da montagem da página Home da loja, ajudando a exibir os produtos, as lojas em destaque e os itens mais próximos do usuário.

Também contribuí com melhorias nas páginas de login e cadastro, ajustando o layout e o CSS para ficarem parecidas com o restante do site.

# Conhecimentos Adquiridos

Durante esta etapa do projeto, aprendi mais sobre:


* Organização de componentes em React
* Criação de elementos de interface reutilizáveis
* Montagem de páginas com várias seções
* Ajustes de estilo com CSS
* Trabalho em equipe usando o GitHub


# Dificuldades Encontradas

Tive dificuldade em deixar os componentes organizados de um jeito que pudessem ser usados em várias partes do site sem bagunçar o código.

Também foi um desafio montar a página Home, já que ela tem várias seções diferentes.

Outra dificuldade foi ajustar as páginas de login e cadastro para ficarem no mesmo padrão visual do resto do site.

# Como as Dificuldades Foram Resolvidas

Resolvi o problema dos componentes separando-os em partes menores e reutilizáveis.

Para a página Home, dividi o desenvolvimento em seções, o que facilitou bastante o trabalho.

Já nas páginas de login e cadastro, fui ajustando aos poucos o CSS até ficarem parecidas com o padrão do site.

# Considerações Finais

Esse período do projeto me ajudou a aprender mais sobre organização de telas e componentes no frontend. Consegui melhorar minha forma de trabalhar com React e CSS, além de praticar mais o trabalho em equipe.
