# Relatório Individual — Gabriel Istchuk

## Projeto: Sellf

Durante este bimestre, participei do desenvolvimento da tela de cadastro de produtos do sistema Sellf. Minha principal contribuição foi na construção da interface, organização dos componentes e implementação das funcionalidades necessárias para o cadastro.

Essa etapa foi importante para tornar o sistema mais completo, permitindo o registro de produtos de forma prática e organizada. Durante o processo, trabalhei com a estruturação da página, estilização e adaptação para diferentes tamanhos de tela.

## Conhecimentos Adquiridos

Durante o desenvolvimento desta etapa, aprendi mais sobre:

* Criação de interfaces com React
* Organização de componentes
* Responsividade com CSS
* Estruturação de páginas para melhor experiência do usuário
* Integração entre front-end e funcionalidades do sistema

## Dificuldades Encontradas

Uma das principais dificuldades foi adaptar a interface para diferentes dispositivos, garantindo que a tela permanecesse organizada e funcional em vários tamanhos de tela.

Também enfrentei desafios na estilização dos componentes e no posicionamento correto dos elementos da página.

## Como as Dificuldades Foram Resolvidas

As dificuldades foram resolvidas por meio de pesquisas, testes práticos e ajustes constantes no código. Busquei referências sobre responsividade e melhores práticas em React para melhorar a organização e funcionamento da tela.

Além disso, utilizei a documentação das ferramentas e contei com a colaboração da equipe para solucionar problemas específicos.

## Considerações Finais

O desenvolvimento da tela de cadastro de produtos contribuiu significativamente para meu aprendizado, principalmente no uso do React, na construção de interfaces responsivas e na organização de componentes.

Esse bimestre foi importante para aprofundar meus conhecimentos em desenvolvimento front-end e fortalecer minha experiência prática no projeto.
