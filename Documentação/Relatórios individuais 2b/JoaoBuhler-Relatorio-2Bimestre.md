# Relatório Individual — João Pedro Buhler

## Projeto: Sellf

Durante o desenvolvimento do projeto Sellf, atuei principalmente no desenvolvimento do backend e na integração com o banco de dados MySQL. Fui responsável pela criação das rotas da API utilizando Node.js e Express, pela conexão entre a aplicação e o banco de dados e pela implementação do CRUD completo de produtos, incluindo cadastro, consulta, edição e exclusão.

Também participei da integração entre o frontend em React e o backend utilizando Axios, garantindo a comunicação entre a interface e os serviços da aplicação.

## Conhecimentos Adquiridos

Durante o projeto, aprimorei meus conhecimentos em:

* Desenvolvimento backend com Node.js e Express;
* Construção de APIs REST;
* Integração entre frontend e backend;
* Manipulação e modelagem de banco de dados MySQL;
* Desenvolvimento de operações CRUD;
* Trabalho em equipe utilizando GitHub.

## Dificuldades Encontradas

As principais dificuldades envolveram a integração entre o backend e o banco de dados, especialmente na configuração dos relacionamentos entre tabelas e na resolução de problemas de codificação de caracteres.

## Considerações Finais

O projeto contribuiu para consolidar meus conhecimentos em desenvolvimento backend, integração com banco de dados e construção de aplicações web, além de aprimorar minha capacidade de resolver problemas e trabalhar em equipe.
