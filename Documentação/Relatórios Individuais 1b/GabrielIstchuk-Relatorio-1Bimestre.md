# Relatório Individual — Gabriel Istchuk

## Projeto: Sellf

Durante o desenvolvimento do projeto Sellf, participei principalmente da criação dos wireframes, documentação e organização geral do projeto.

Os wireframes ajudaram no planejamento das telas e na definição da navegação do sistema. Também produzi documentos importantes, como descrição do sistema, guia de instalação e organização das funcionalidades.

## Conhecimentos Adquiridos

Durante o projeto, aprendi mais sobre:

- Organização de projetos web
- Planejamento de interfaces
- Documentação técnica
- Trabalho em equipe utilizando GitHub

## Dificuldades Encontradas

Uma das dificuldades foi organizar toda a documentação de forma clara e padronizada. Também tive dificuldade em criar wireframes simples e funcionais ao mesmo tempo.

## Como as Dificuldades Foram Resolvidas

Pesquisei modelos de documentação e referências de interfaces para melhorar a organização do projeto e a criação das telas.

## Considerações Finais

O projeto foi importante para desenvolver meus conhecimentos em desenvolvimento web, organização de projetos e trabalho em equipe.
